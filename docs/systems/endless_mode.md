## Purpose
The never-ending mode: purchasable arena skins over one shared floor, waves and bosses drawn from the
Rifts the player has cleared, and the best score and wave to chase. The daily run uses its rules.

## Rules & behaviour
- **Continuous spawning** (owner 2026-09-15): a new formation arrives whenever at most
  `refill_live_enemies` (2) enemies are alive, and a spent wave starts the next at once — no quiet waits.
  Story Rift levels keep the timed waves.
- **Home's PLAY starts Endless** and it is open from the first launch (owner decision 2026-09-15); there is
  no ENDLESS button or unlock gate, and arena skins can be bought any time. Real runs never teach: the
  first launch opens the Tutorial screen instead ([tutorial.md](tutorial.md)). The pool is every Rift's roster and boss from the start; story clears never
  change it (owner decision 2026-09-15).
- The wall is `EndlessCatalog.floor_polygon` for every skin, mapped like a Rift polygon; a skin changes
  only the background.
- No rule twist: no portals, shrinking floor, drift or boss rush.
- Each non-boss wave uses one cleared Rift's `enemy_substitutions`, seeded by the run seed and wave
  number; never the same roster twice in a row when two or more are available.
- Every `boss_wave_interval` waves, one beaten boss arrives (seeded, no immediate repeat). A victory
  raises the cycle and resumes waves; it never ends the run. Death ends it.
- Best score, best wave and run count belong to Endless. Depth milestones stay keyed on the lifetime
  best wave, which only Endless and daily runs can push past wave 4.
- Daily run: Endless rules, the date seed, the fixed daily pool and the arena of the day (any of the 30
  skins, by date seed); identical for every player on a date.
- **Animated scenery** (owner decision 2026-09-15; rebuilt after the device test, owner feedback 2026-09-15
  "make them better, more vibrant; Mythic shall be felt"): the effects use the painting itself.
  - **Mask** per Legendary/Mythic skin (`endless_scenery.py`, 471×836 RGBA, lossy import): R = the painting's
    own light sources (brightness / top-hat / hue rules inside tunable UV rects per zone), G = regions that may
    distort (water, fire, aurora, clouds, mist), B = scenery weight (0 on the floor template, linear to 1 across
    the 48 px rim tolerance), A = zone id (`255 − id × 28`, nearest-sampled, ≤ 7 zones). R and G are zero until
    16 px past the rim tolerance.
  - **Shader** (`arena_scenery.gdshader`, one pass on the backdrop, ≤ 4 texture reads, no loops): scenery gets
    saturation, contrast, exposure and a split-tone lift toward the skin's palette (Mythic stronger); the floor gets
    only `floor_saturation` ≤ 1.12 with its luminance kept, so the Wisp stays the brightest small object (GDD §9).
    Emissive light per zone (breathing, flicker, flares, colour cycling and spatial shift, twinkle, travelling
    pulses) is added bloom-like on R; distortion per zone (ripple, shimmer, wave, roil; a few px) moves G.
    Set pieces: CORONA (counter-rotating rays + flare lobes) and SWIRL (flow-map rotation that never accumulates);
    optional light sweep (god rays / glints, weighted per zone) and shooting stars. All gated by B ≈ 1.
  - **Particles**: one CPUParticles2D per emitter (additive soft dot or the collectible sparkle; smoke normal
    blend), spawned only at generator-sampled points whose whole drift path stays outside the floor + rim
    tolerance (`EndlessCatalog.validate_scenery`), and faded per pixel by mask B, so none can show over the floor.
  - Time-based values (levels, tints, flares, corona rotation, swirl phase, sweep, streak) are computed in
    `ArenaAmbience._process` (pausable), so everything freezes with the paused run. Lightning-like flashes are
    soft and at most every 6 s (`MIN_FLASH_INTERVAL`), never a strobe.
  - **Reduced Motion**: static grade + steady emissive only (no distortion, sparkle, pulses, flares, sweeps,
    streaks or particles). **Shop ARENAS** thumbnails use the same static material; the animation plays only in
    a run. Collision and the floor polygon are untouched.

## How to test
- `tools/run_tests.sh endless_catalog`.
- Visual: `tools/qa_matrix.sh endless_astral_observatory endless_storm_anvil endless_aurora_throne`; every skin: `render_endless_skins_sheet.gd` (command in its header) → `logs/endless/run_sheet_{1,2}.png`; animated scenery: `render_endless_scenery_sheet.gd` (3 frames per Legendary/Mythic skin; `--band=0,0.24 --tile=400` for close-ups).
- Scenery tuning loop: edit `SCENERY` in `tools/art/endless_scenery.py` → run it (masks + `logs/endless/scenery_masks_preview.png`: R red, G green, emission points white) → `make_endless_skin_data.py` → `tools/validate.sh` → render sheet.

## Known issues / TODO
- Device pass pending: rim at the wall, lossy art quality, and the scenery shader + particles' cost and look on the owner's phone.
- Set pieces at the very top (eclipse corona, galaxy, gate seam) sit partly behind the HUD score box on phones; the bottom band carries most of the visible scenery.
- The painted rim inside the rim tolerance gets part of the scenery grade (B ramps across it), e.g. a warmer bone rim on dragon_skull_throne.
- Bright top scenery sits behind the HUD text on a few skins (quartz_grotto, slate_cliffs, dusk_sandstone, eclipse corona); HUD legibility needs a look on device.
- Generated-art licence to confirm before release (GDD §14 #1, #21).
- Endless events built from the Rift twists are backlog.
