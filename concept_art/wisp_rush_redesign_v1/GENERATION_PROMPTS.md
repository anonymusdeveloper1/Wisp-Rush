# Generation prompt set

All images were created with the built-in image-generation workflow. The Pinterest images were
style/composition references only; subsequent prompts used the newly generated Wisp Rush visual
target to keep the pack internally consistent.

## Shared art-direction block

```text
Original hand-painted 2D game art with crisp pixel-inspired silhouettes and selective hard edges.
Ancient overgrown obsidian sanctuary; premium indie mobile-game finish; portrait readability.
Palette: charcoal #111521, slate teal #263D42, cyan #62E8F2, soul white #EAFDFF,
warning amber #F3A847, rift magenta #B14CD9. No copied characters, logos or layouts.
```

## 01 — Visual target key art

```text
Create a polished 9:16 top-down supernatural action scene. A compact cyan-white non-human Wisp
ricochets across a ruined rift arena through two original shadow creatures; a hooded Reaper waits
at a sealed gate. Keep the central playfield clear and leave HUD-safe space. No words, logos,
watermarks, humans, guns or copied characters.
```

## 02 — Gameplay arena floor

```text
Create an empty continuous 9:16 obsidian sanctuary floor behind 2D gameplay sprites. Cracked slate
tiles, low-contrast moon rune, sparse moss and perimeter-only broken ruins/braziers. Keep the central
75% uninterrupted. No characters, pickups, UI, baked combat effects or central collision props.
```

## 03 — Home background

```text
Create a cinematic 9:16 Home background with a compact cyan-white soul-flame Wisp above a crescent
rune, floating ruins and a distant rift. Reserve the upper 22% for title and dark lower 30% for
buttons. No baked UI, words, logos, frames or extra characters.
```

## 04 — Shared menu background

```text
Create a quiet low-detail 9:16 background of distant floating ruins in cyan mist, with decoration
only at the outer edges and a low-contrast center for panels. No subjects, UI, text or bright focal
objects.
```

## 05 — Wisp animation sheet

```text
Create a transparent 4×3 sheet of one consistent teardrop soul-flame Wisp with midnight core and
two eye lights. Poses: idle A, idle B, aim, charge, dash left, dash right, soul reap, wall impact,
hurt, death, reform, victory. Consistent anchors and scale; no environment, grid, text or extra poses.
Then remove all unattached background energy while preserving the twelve poses.
```

## 06 — Enemy animation sheet

```text
Create a transparent 3×4 sheet. Columns: round charcoal Soul Wisp with magenta core; angular
crystal-armored Shard Wraith; ivory skull-and-rib Bone Mote held by cyan flame. Rows: idle A,
idle B, hit, defeat. One isolated enemy per cell, strong mobile silhouettes, no floor or labels.
Then extract the baked checkerboard to genuine alpha without restyling.
```

## 07 — Reaper animation sheet

```text
Create a transparent 4×3 Reaper boss sheet: tall faceless midnight robes, cyan crescent mask,
black antler crown, obsidian scythe with magenta runes. States: idle A/B, gate arrival, windup,
sweep, vanish, appear, exposed core, hit, corridor cast, stagger, defeat. Preserve full scythe and
antlers. Then extract the baked checkerboard to genuine alpha.
```

## 08 — Hazards and pickups

```text
Create a transparent 4×3 top-down atlas: dormant/warning/active split void crystal; closed/warning/
open spike bloom; resting/warning/spinning blade ring; Soul Shard, shard cluster and rift portal.

```

## 09 — Additive VFX

```text

```
