# Reference synthesis

The owner supplied six Pinterest pins as visual references. The downloaded reference images were
used for analysis and image-generation context only; they are not included in this project folder.
The generated pack intentionally synthesizes general visual principles rather than copying any
single composition, character or interface.

| Reference | Observed contribution to the direction |
|---|---|
| [Top-down dark mobile combat](https://pin.it/6Gl84bnNV) | Dense but readable ruined floor, compact status HUD, strong enemy silhouettes and tactical line effects. |
| [Overgrown monumental mobile world](https://pin.it/6kyFDavXt) | Painterly vegetation, ancient monumental focal point, sunny depth layering and UI floating over a living environment. |
| [Pixel-art biome scenes](https://pin.it/2ZZzX14VX) | Crisp pixel-inspired contour language, readable top-down characters and distinctive biome palettes. |
| [Magical arena combat](https://pin.it/7HeFZTyx1) | Restrained dungeon floor, bright attack contrast and highly legible amber hazard telegraphs. |
| [Portrait action-survival layout](https://pin.it/55DcFoigR) | Phone-first combat framing, compact top HUD, pickups, skill feedback and open thumb-space near the bottom. |
| [Luminous forest spirit](https://pin.it/3YUX7D9lV) | Small glowing creature against a deep blue environment, cinematic rim lighting and soul-mote atmosphere. |

## Resulting original direction

The redesign combines top-down clarity, painterly environmental depth, crisp sprite silhouettes,
cyan soul magic, amber warnings, magenta threats and dark engraved UI. It retains Wisp Rush's own
Wisp, dash, Reaper, forms, mutations and mobile portrait structure.
